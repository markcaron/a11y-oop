# Handoffs

Carry scope ID/version, revision, required coverage units, results, finding IDs, evidence artifacts, unresolved questions, limitations, and next methods. Preserve failed/unresolved occurrences when deduplicating.

The receiving task validates scope, revision, and available evidence. Record scope changes explicitly. Missing artifacts become gaps rather than silent omissions or finding closures.

Source review ends with a runtime queue. Keyboard testing ends with observed transitions and remaining needs. Reporting ends with coverage, unresolved findings, and next actions. Every skill also supports independent invocation; a separate planning skill is not required.

Carry required and available browsers, state/transition expectations, and inspection-tool capabilities. For cross-root work, include the endpoint/root/mechanism map and unresolved relationship observations. Retesting must identify which browser/state units it covers; no global closure from a single-browser repeat.
