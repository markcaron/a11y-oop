# Coverage and consolidation

Count required result units, not arbitrary observations. Preserve source, keyboard, browser-tree, automated, and human AT origins. Record each scoped unit using the result statuses, with reasons for exclusions and gaps.

A source Pass and keyboard Fail can coexist: report the keyboard failure. Keep states, environments, and revisions distinct. A newer source pass cannot close an older runtime finding.

For conflicting comparable observations of the same unit, retain both, mark the current determination Inconclusive, and leave associated findings open. Do not erase a failing observation because a repeat passed.

Group shared causes under stable finding IDs without losing affected occurrences or result IDs. Close findings only with explicit evidence-backed dispositions in matching retest scope. Nonreproduction alone does not prove a fix; retesting one environment does not establish all environments.

A scoped check passes only when all required applicable units pass. Keep failures visible alongside gaps. Show status/method counts with the scope denominator. Checklist completion is not a conformance percentage; this pilot cannot certify a product.
